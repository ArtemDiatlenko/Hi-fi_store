# UI pilot imagery

`amplifier-study.webp` is a fictional amplifier illustration, generated with the built-in imagegen tool for this UI pilot. It is not a photograph of an actual catalog item. The homepage labels it as a demo illustration and keeps it separate from actual product cards.

The project asset was encoded to WebP at quality 88 without changing the composition.

## Final prompt

Use case: product-mockup. Create a quiet editorial product photograph for a boutique hi-fi workshop website design prototype. Subject: one fictional handcrafted vacuum tube stereo amplifier, warm brushed silver aluminum faceplate, two elegant large rotary knobs, dark walnut side cheeks, four glass vacuum tubes and two matte black transformer housings on the top. No visible brand, text, logos or lettering. The whole amplifier sits low in the frame on a pale warm stone tabletop against a warm off-white studio background, with a very soft natural shadow and soft daylight from the upper left. Three-quarter front view from slightly above, close enough to appreciate metal, glass and walnut materials; the entire product is in frame, occupying most of the image width. Clean realistic industrial construction, understated European audio editorial photography, restrained, no dramatic glow, no colored lights, no smoky backdrop, no gradients as graphic effects, no decorative props, no people. Landscape 3:2 framing, high detail. This is an explicitly fictional demo image for a UI template, not a depiction of a real commercial product.
