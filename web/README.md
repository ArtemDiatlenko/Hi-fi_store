# Hi-fi Store — витрина (Next.js)

Next.js (App Router) + TypeScript + Tailwind. Данные берутся из ASP.NET Core API (`api/`).

```bash
npm install
npm run dev        # http://localhost:3000, API ожидается на http://localhost:5166 (переменная API_URL)
npm run lint
npm run build
```

Страницы (украинская версия — без префикса, английская — под `/en`):

- `/` — главная: hero, разделы каталога, новинки, скидки (товары со старой ценой), бренды, преимущества;
- `/catalog` — каталог; фильтры — обычная GET-форма, состояние хранится в адресной строке;
  поиск из шапки ведёт сюда с `q=`;
- `/products/[slug]` — карточка товара: галерея, хлебные крошки, характеристики, похожие товары, кнопка «В корзину»;
- `/info/delivery`, `/info/returns`, `/info/contacts` — информация для покупателей. **Текст шаблонный**
  (раздел `info` в `lib/i18n/dictionaries.ts`, помечен плашкой «Зразок тексту») — замените его условиями магазина;
  контакты-заглушки — в `lib/site.ts` (`STORE_CONTACTS`, после замены выставьте `placeholder: false`);
- `/cart` — корзина (хранится в `localStorage`, цены пересчитываются через API);
- `/checkout` — оформление заказа, гостем или после входа;
- `/orders/[token]` — страница подтверждения заказа по публичному токену;
- `/login`, `/register`, `/account` — вход, регистрация и профиль по bearer-токену;
- `/account/orders`, `/account/orders/[id]` — заказы покупателя.

Шапка: меню разделов (выпадающее на десктопе, в мобильном меню на телефонах), поиск, корзина, язык,
ссылка «Увійти»/«Акаунт» по состоянию входа и ссылка на `/admin` — только для роли `Admin`
(проверяется в браузере через `GET /api/account/me`, см. `lib/session.ts`).

Оформление: графитовые нейтральные тона (Tailwind `zinc`) и латунно-янтарный акцент (`amber`),
светлая и тёмная темы по `prefers-color-scheme`; токены — в `app/globals.css`.

Подробнее о запуске и API — в корневом `README.md`.
